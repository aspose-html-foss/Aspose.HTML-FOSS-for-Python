# Changelog

## 0.1.0

Initial public source snapshot of Aspose.HTML FOSS for Python.

- HTML parsing from strings, bytes, fragments, and files
- DOM document, node, element, attribute, collection, traversal, event, and range surfaces
- Common HTML element classes for document manipulation workflows
- HTML serialization helpers
- URL and URL search parameter helpers
- CSS selector, CSSOM declaration/rule, and computed-style foundations used by DOM workflows
