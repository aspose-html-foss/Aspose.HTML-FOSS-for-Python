# Contributing

Thank you for your interest in contributing to Aspose.HTML FOSS for Python.

## Development Setup

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -e .[test]
```

## Running Tests

```bash
python -m pytest
```

## Guidelines

- Keep public APIs documented with runnable examples when practical.
- Add or update tests for behavioral changes.
- Prefer small, focused changes.
- Follow the existing package layout and naming conventions.
- Do not include generated caches, local environment files, credentials, or private tooling output.

## Reporting Issues

Please use GitHub issues with a minimal reproduction, expected behavior, actual behavior, and Python version.
